# AI MIL Trainer UI

Перший UI-прототип навчального Dashboard.

## Запуск

З кореня репозиторію:

```bash
streamlit run src/ai_trainer/app.py
```

## Важливо

Це навчальний MVP. Він не підключений до зовнішньої AI-моделі.
Приклади є умовними та не призначені для роботи з реальними чутливими
оперативними даними.

Наступний технічний етап: винести навчальний контент у окремі файли,
додати збереження результатів, а потім підключити AI-провайдер через
окремий адаптер.
